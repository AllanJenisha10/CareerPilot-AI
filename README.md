## 🎯 About the Project

CareerPilot AI is an AI-powered career guidance platform designed to help students, graduates, and job seekers explore career opportunities, understand their skills, and plan their professional development.

The platform combines a user-friendly interface with Google Gemini AI to support career exploration and personalized learning guidance.

## ✨ Key Features

- 🎯 **Career Recommendations** — Explore career paths suited to your interests and goals.
- 🧠 **Skill Assessment** — Review your current skills and development areas.
- 📊 **Visual Analytics** — Present career or skill information using the charts implemented in the application.
- 🔍 **Skill-Gap Analysis** — Identify skills to develop for a target career.
- 🗺️ **Learning Roadmaps** — Organize learning goals into a structured path.
- 📄 **Resume Assistance** — Get guidance for improving resume content.
- 🤖 **Gemini AI Integration** — Support AI-powered career guidance.
- 📱 **Responsive Interface** — Navigate the application on supported screen sizes.
