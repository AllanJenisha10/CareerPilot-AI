## ✨ About CareerPilot AI

**CareerPilot AI** is an AI-powered career guidance platform designed to help students, graduates, and job seekers explore career opportunities, understand their skills, and plan their professional growth.

By combining an intuitive user experience with Google Gemini AI, the project aims to make career exploration and preparation more accessible.

| Explore careers | Understand skills | Build roadmaps | Prepare for opportunities |

</div>

### Installation

**1. Clone the repository**

```bash

```

**2. Enter the project directory**

```bash

```

**3. Install dependencies**

Use the package manager and commands specified by the project's configuration files.
